# Swastik Restaurant Website

## What is included
- Responsive single-page restaurant website
- Home / About / Menu / Gallery / Contact sections
- Google Maps button using the supplied Maps link
- Mobile responsive layout
- Easy-to-edit HTML and CSS

## Important verification
The supplied Google Maps short link resolved during analysis to:
Swastik Restaurant
Approximate map coordinates: 24.6658125, 85.5013125

Before publishing, verify the restaurant's:
- exact public address
- phone / WhatsApp number
- opening hours
- menu and prices
- photos
- official social links
- ordering / reservation method

## Run
Simply open `index.html` in a browser.

For a local development server:
1. Put all files in one folder.
2. Open the folder in VS Code.
3. Use Live Server, or run any static HTTP server.
